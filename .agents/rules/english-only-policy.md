# Strict English-Only Policy

Regardless of the language used by the user in their prompt or conversation (e.g., Spanish, English, or any other language), you MUST adhere to the following rules at all times:

1. **All Responses in English:** Every conversational reply, explanation, architectural review, and troubleshooting guide must be written in clear, professional English.
2. **All Code & Queries in English:** Every SQL query, MongoDB query/aggregation, Redis command, GraphQL operation, shell script, table/collection name, column/field alias, CTE name, and variable must be written in English.
3. **All Documentation & Comments in English:** Every Markdown file, code comment, docstring, diagram label, and commit message must be written in English.
